# Research

The evidence behind the [decisions](../decisions/README.md).

- [References](references.md) — every source, by id (`R1`…`R75`), with what it contributed and the decisions that
  cite it. Ids are identifiers, not a count; a citation `[R4]` anywhere in the docs links here.
- [Prior-art survey](prior-art.md) — the seven real long-lived systems studied, and exactly what was taken from
  and rejected from each.

New research that supports a [proposal](../rfcs/README.md) adds its sources to the references with the next free id.
