# NNNN — The proposed change, in one line

- **Date:** YYYY-MM-DD
- **Status:** draft
- **Answers:** the [issues](../issues/README.md) behind it (a proposal without a real incident is not considered)

## Problem

What the issues show the schema cannot do, or does wrong.

## Options

Each option: the change to [schema.sql](../schema/schema.sql) and the pages it touches; whether it is additive
(after the freeze only additive changes are possible, [D13](../decisions/D13-migrations-and-freeze.md)); what it makes
redundant; what it costs.

## Recommendation

The option to take, and why.

## Validation

The suites and mutants that will show the change holds (`tests/README.md`), and any SQLite behaviour that must be
executed before it is claimed.

## Outcome

Filled in when it closes: the decision it became, or why it was rejected.
